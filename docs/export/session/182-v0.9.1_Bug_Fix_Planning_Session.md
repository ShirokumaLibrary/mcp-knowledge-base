## 技術的な発見

### タイムアウト処理の不要性
- `SHIROKUMA_EXPORT_TIMEOUT`は防御的プログラミングの名残
- エクスポートは100ms以下の軽量なローカル処理
- むしろ正常処理を妨げるリスクあり

### 修正方針
```typescript
// シンプルな解決策
const freshItem = await itemRepo.findById(item.id);
if (freshItem) {
  await exportManager.autoExportItem(freshItem);
}
```
