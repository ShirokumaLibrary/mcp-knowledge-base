# v0.9.0 Critical Bug Fixes Session

## 作業概要
v0.9.0の重大なバグ修正と機能改善を実施

## 完了した修正

### 1. search_items API修正
- **問題**: 構造化クエリ（`status:Open`等）が動作しない
- **解決**: 
  - SearchQueryParserクラスを実装
  - ItemRepository.searchAdvanced()メソッドを追加
  - 構造化クエリのサポート（status:, type:, is:, priority:）

### 2. is_closableフラグ修正
- **問題**: SQLiteでboolean値が全て0になる
- **解決**:
  - InitialMigrationにUPDATE文を追加
  - StatusRepositoryでフラグ管理を改善

### 3. import/export改善
- **問題**: 
  - system_stateインポートが失敗
  - Unknownステータスが自動作成される
  - IDが保持されない
- **解決**:
  - latest.mdをスキップして番号付きファイルのみ処理
  - デフォルトでID保持（上書き可能）
  - Unknown→Openにフォールバック
